# OpenCode V2: Multi-Agent setup

Шесть агентов для личных проектов. Язык общения — русский, промпты агентов — английский.

## Состав

- `lead` — **primary**; только делегирует через `subagent`, не читает и не пишет код, не выбирает стек.
- `solo` — **primary**; самостоятельно решает небольшие задачи.
- `senior-developer` — **subagent**; пишет продакшен-код, тесты, выбирает простую архитектуру и согласовывает серьёзные компромиссы.
- `qa-engineer` — **subagent**; независимо проверяет требования и тестирует, не редактирует файлы.
- `explorer` — **subagent**; исследует код, документацию и интернет, не редактирует файлы.
- `code-reviewer` — **subagent**; независимо ревьюит реальные изменения, без редактирования.

## Установка

1. Проверь версию: `opencode --version`. **Этот пакет — для V2**, не V1.
2. Создай папку: `mkdir -p ~/.config/opencode/agents`.
3. Скопируй **только шесть файлов** из `agents/` в `~/.config/opencode/agents/`.
4. `AGENTS.md` можно скопировать в `~/.config/opencode/AGENTS.md` (рекомендуется).
5. Файл `opencode.json.example` — пример глобальных разрешений и `default_agent`. **Не заменяй им свой `opencode.json` целиком**, объедини нужные поля с существующей конфигурацией.
6. Перезапусти OpenCode или начни новую сессию. Переключай primary-агента между `lead` и `solo`.

Проверка: `opencode agent list` (если команда доступна в вашей версии). Список моделей: `opencode models` или `/models`.

## Модели (предполагаемые model ID)

- Lead — `openai/gpt-6-luna`
- Senior Developer и Solo — `openai/gpt-6.1-sol`
- QA и Explorer — `google/gemini-3.8-flash`
- Code Reviewer — `openai/gpt-6-astra`

Названия моделей взяты из списка пользователя. **Точные `provider/model-id` не подтверждены подключением к вашему OpenCode**. Если модель не найдена, посмотри её ID в `opencode models` и исправь `model:` в соответствующем `.md`.

У primary-агента (особенно `solo`) активная модель в существующей сессии может отличаться от указанной в `model:` — переключение primary-агента не всегда меняет модель, выбранную ранее в сессии. Начни новую сессию или выбери модель через `/models`.

## Безопасность и ограничения

- Запреты в `AGENTS.md` — инструкции модели; реальные ограничения инструментов задаются `permissions` в frontmatter.
- Lead запрещены все инструменты кроме вызова 4 субагентов и вопросов пользователю.
- Другим агентам запрещено делегировать.
- QA и Reviewer не могут использовать `edit`, но запуск тестов и shell-команд потенциально имеет побочные эффекты; поэтому опасные команды требуют разрешения или запрещены.
- По умолчанию тесты Go (`go test`, `go vet`) разрешены, другие shell-команды у исполнителя и QA обычно требуют подтверждения.
- Другие языки поддерживаются, но правила Go активируются только в Go-проектах.
- Подагенты имеют отдельный контекст и собственные разрешения.
